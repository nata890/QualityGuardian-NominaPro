## ADDED Requirements

### Requirement: Guardian Agent artifacts SHALL be written to .planning/ as DRAFT first
All artifacts generated by the Guardian Agent (`test_engine.py`, `veredicto.json`) SHALL be written to `.planning/fix-all-audit-issues/` before being copied to their production paths. The human responsible SHALL approve the move from DRAFT to production.

#### Scenario: test_engine.py is written to .planning/ first
- **WHEN** guardian_client.py generates tests
- **THEN** the output file is written to `.planning/fix-all-audit-issues/test_engine.py`

#### Scenario: veredicto.json is written to .planning/ first
- **WHEN** guardian_client.py emits the verdict
- **THEN** the output file is written to `.planning/fix-all-audit-issues/veredicto.json`

### Requirement: Oracle artifacts SHALL be written to .planning/ as DRAFT first
The Oracle Agent's output (`casos_prueba.md`) SHALL be written to `.planning/` as a DRAFT before being moved to the production path.

#### Scenario: casos_prueba.md DRAFT exists before production
- **WHEN** the Oracle generates test cases
- **THEN** the file is first created in `.planning/` and only moved to the root after human approval

### Requirement: .planning/ directory SHALL be excluded from .gitignore
The `.planning/` directory SHALL NOT be in `.gitignore` so that DRAFT artifacts are tracked in version control for audit purposes.

#### Scenario: .planning/ is tracked by git
- **WHEN** checking git status after creating a DRAFT
- **THEN** files in `.planning/` appear as tracked or untracked (not ignored)
